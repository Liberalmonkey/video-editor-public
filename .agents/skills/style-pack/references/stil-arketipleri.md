# Stil arketipleri — ortak sözlük

Kullanıcı "Vox gibi", "Kurzgesagt tarzı" dediğinde ya da motion dosyası tarif ederken bu sözlüğü kullan. Arketip **başlangıç noktasıdır**; paket her zaman kullanıcının kendi referanslarından ölçülerek yazılır (STYLE.md'de "referansta ölçülen" sütunu). Bu sayfadaki özellikler genel gözleme dayanır, kaynaklı değildir.

| Arketip | Görsel dil | Hareket dili | Ses | Nerede |
|---|---|---|---|---|
| **Vox açıklayıcı** | Kağıt/kolaj dokusu, krem-bej zemin, siyah + tek kırmızı/sarı vurgu, arşiv fotoğrafı kesikleri, el yazısı not, vurgulu (highlighter) metin | Kısa kaymalar, kağıt gibi katman katman açılma, harita zoom'u, arşiv belgede kamera gezinmesi | Ambient synth / hafif elektronik, minimal SFX (kağıt, kalem) | YouTube eğitici |
| **Kurzgesagt / flat-vektör** | Doygun ama uyumlu palet (lacivert zemin + turuncu/turkuaz), yuvarlak geometrik karakterler, kontursuz düz vektör, yumuşak glow | Sürekli yavaş hareket (arka plan asla durmaz), paralaks, organik easing, ölçek geçişleri | Orkestral-ambient, yumuşak SFX | Bilim anlatımı |
| **Johnny Harris / harita belgesel** | Gerçek harita + uydu görüntüsü, kağıt harita dokusu, kırmızı çizgi/ok, el çizimi işaret | 3D harita uçuşu, çizgi çizilmesi, pin düşmesi | Gerilimli sinematik fon | Coğrafya, tarih |
| **Kinetik tipografi (minimal)** | Tek renk zemin, büyük kalın sans, tek accent | Kelime kelime giriş, sert kesmeler, ritme kilitli | Beat odaklı müzik, tik/pop | Reels hook, özet |
| **Whiteboard / el çizimi** | Beyaz zemin, siyah marker çizgisi, az renk | Çizgi çizilerek belirme (SVG draw), el imleci | Kalem/marker SFX, sakin akustik | Ders anlatımı |
| **Teknoloji / UI demo** | Koyu zemin, cam (glass) paneller, ince kontur, mono font, ekran kaydı çerçeveleri | İmleç takibi, UI zoom/punch-in, maske reveal | Elektronik, tık/klavye SFX | Yazılım tanıtımı |
| **UGC native** | Gerçek çekim, telefon oranı, kalın beyaz altyazı (siyah stroke), sticker/emoji az | Punch-in, jump cut, hızlı B-roll | Trend hissi veren pop/lo-fi, gerçekçi SFX | UGC, satış |
| **Reels bold-pop** | Yüksek kontrast, büyük kelime vurgusu, renkli altyazı kutusu | Hızlı (in 0.3 sn), overshoot, sık kesme (1–2 sn) | Enerjik 110–130 BPM, whoosh/pop yoğun | Instagram |
| **Premium / kurumsal** | Bol boşluk, ince serif ya da geometrik sans, nötr palet + metalik accent | Uzun, yumuşak easing (0.6–0.9 sn), az hareket | Piyano/strings, çok az SFX | Marka, ürün lansmanı |
| **Retro / VHS** | Grain, renk kayması (chromatic aberration), CRT tarama çizgisi, 4:3 çerçeve | Glitch geçiş, titreme | Synthwave, kaset sesi | Nostalji, eğlence |

## Tarif ederken
"Vox tarzı" tek başına yeterli değil; her zaman somut özellikleri aç: **doku + palet + font karakteri + hareket karakteri + ses.**
Örnek: "Vox tarzı = kağıt dokulu krem zemin, siyah metin, tek kırmızı vurgu, highlighter efektli kelimeler, katman katman kayan kolaj; fon müziği ambient synth 80–95 BPM."
