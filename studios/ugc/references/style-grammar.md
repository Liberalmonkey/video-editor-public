## İki görsel mod
**A. Konuşan kafa + cam katmanlar** (0:02–0:09, 2:48)
- Konuşmacı ortada; iki yanında **buzlu cam (frosted glass) hap/kart**: yarı saydam gri (#78807E ~%35), 1px beyaz kenar (~%22), büyük yarıçap (~24px), arkası bulanık.
- Hap içi: solda kare ikon karosu (hafif beyaz zemin), sağda beyaz yarı-kalın sans etiket ("Motion design", "Sound design"); karşılaştırmada iki taraf simetrik ("Fable 5.1 | GPT-6 Astra").
- Kart varyantı: üstte medya (ekran kaydı / screenshot / küçük resimler + yeşil onay rozetleri), altta ikon + başlık + gri alt satır ("Verification — Every frame checked…").
- Kartlar konuşmacının yüzünü asla kapatmaz; göz hizasının biraz altında, kenarlara yakın.
- **Altyazı:** alt-orta, beyaz yarı-kalın sans, söylenmiş kelimeler beyaz + altında ince vurgu çizgisi, henüz söylenmemiş kelimeler %45 beyaz (karaoke-dim). Kutu yok, gölge hafif.

**B. Koyu HUD showreel** (0:13–0:24, 7:33–7:47)
- Zemin neredeyse siyah, ince nokta ızgarası, köşe braketleri (⌐ ¬), merkezde hafif vinyet.
- HUD metinleri: üst-sol "● AIS / MOTION REEL 2026" (mono, büyük harf, geniş harf aralığı), üst-sağ "TC 00:00:05:32 / 1920×1080 · 60P", alt-sol "03 3D CAMERA" (bölüm no + ad), alt-sağ "122 BPM ▮▮▮▮" seviye göstergesi, altta ince ilerleme çubuğu (segmentli).
- Tek vurgu rengi glow ile (mavi; bizde marka yeşili). Diğer her şey beyaz/gri.
- Sahne türleri: ışık noktası → lazer çizgi; bulanıktan netleşen dev kelime; **düğüm akışı** (yuvarlak köşeli koyu kutular, mavi glow kontur, kavisli bağlantı çizgisi, köşede beyaz onay rozeti, üstte mono etiket TRIGGER / AI AGENT / ACTION / OUTPUT); **3D kart duvarı** (perspektifli ızgara, kamera kayar, seçili kart glow kenarlı öne çıkar); topluluk ızgarası; parçacık; dev sayı sayacı (450,000); 3D cam logo + tagline.

## Geçişler
- Konuşan kafa ↔ HUD: sert kesme, vuruşa denk.
- HUD içinde: kamera itme/çekme (zoom-through), bulanıklık ile netleşme, ışık çizgisi silme.
- Kart girişleri: alttan/yandan kısa kayma + opaklık + hafif bulanıklıktan netleşme (~0.4 sn), çıkış hızlı solma.

## Renk / tipografi
- Mod A: gerçek oda renkleri + nötr gri cam. Mod B: siyah + beyaz + tek glow rengi; ikincil kırmızı (#E5484D) yalnızca "LIVE"/uyarı.
- Fontlar: cam etiketlerde SF/Inter benzeri grotesk; büyük sayı/logo geometrik kalın sans; HUD'da mono büyük harf.

## Ses
- Elektronik, 120–125 BPM, net kick; geçişlerde whoosh, kart girişlerinde yumuşak "tick/pop", sayı sayacında dijital ticking, logo vuruşunda impact.
